AI Art Assistant

A Krita side panel for artist-controlled, non-destructive image edits. The artist keeps the original layers. Later versions will send the visible canvas and an optional selection stencil to a cloud image editor and put the result on a new layer.

This version

The panel can export the visible canvas, export a selection stencil, and import a PNG as a new layer. Generate / cloud edit is not built yet.

Usage

  1. Enable the plugin in Settings, Configure Krita, Python Plugin Manager.
  2. Restart Krita.
  3. Create or open an image (Dockers stay grey on the Start screen).
  4. Show the panel from Settings, Dockers, AI Art Assistant.
  5. Export visible picture, optionally export a selection stencil, then import a PNG.
