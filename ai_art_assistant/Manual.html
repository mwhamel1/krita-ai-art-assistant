AI Art Assistant

A Krita side panel for artist-controlled, non-destructive image edits. The artist keeps the original layers. Generate sends the visible canvas to OpenAI Image Edit and can apply the result as a new layer.

This version

Export/import work locally. Generate uses gpt-image-2.5-flare, one image per click. A selection mask is guidance only; clipping to the selection is not built yet. API keys go in Windows Credential Manager, not in the Krita file.

Usage

  1. Enable the plugin in Settings, Configure Krita, Python Plugin Manager.
  2. Restart Krita.
  3. Create or open an image (Dockers stay grey on the Start screen).
  4. Show the panel from Settings, Dockers, AI Art Assistant.
  5. Save an OpenAI API key in Settings (API credits, not ChatGPT Plus).
  6. Type an instruction and press Generate. Apply, Discard, or Retry the candidate.
