AI Art Assistant

A Krita side panel for artist-controlled, non-destructive image edits. The artist keeps the original layers. Later versions will send the visible canvas and an optional selection stencil to a cloud image editor and put the result on a new layer.

This version

The panel loads, shows the open document name and size, and shows whether a selection exists. Export, import, and Generate are visible but not built yet.

Usage

  1. Enable the plugin in Settings, Configure Krita, Python Plugin Manager.
  2. Restart Krita.
  3. Show the panel from Settings, Dockers, AI Art Assistant.
  4. Open a drawing and click Refresh if the labels look stale.
