AI Art Assistant

A Krita side panel for artist-controlled, non-destructive image edits. The artist keeps the original layers. Generate sends the visible canvas, or the selected sketch, to OpenAI Image Edit and can apply the result as a new layer.

This version

Export/import work locally. Generate uses gpt-image-2.5-flare (faster) or gpt-image-2.5-sunburst (more precise), one image per click. A selection is cropped and sent as a full sketch (enlarged if OpenAI needs a bigger image, no mask). The plugin then clips the preview and new layer to that selection. Cancel ignores the result. API keys go in Windows Credential Manager, not in the Krita file.

Usage

  1. Enable the plugin in Settings, Configure Krita, Python Plugin Manager.
  2. Restart Krita.
  3. Create or open an image (Dockers stay grey on the Start screen).
  4. Show the panel from Settings, Dockers, AI Art Assistant.
  5. Save an OpenAI API key in Settings (API credits, not ChatGPT Plus).
  6. Type an instruction and press Generate. Apply, Discard, Retry, or Cancel.
